A make.fun entry for [The poem about stopping](https://make.fun/c/the-poem-about-stopping-20261121-1927).

`main.ts` (Node 22) writes one short poem about agency — the power to
stop and to stay — to `/output/entry.txt`. The poem is fixed and
deterministic: the same 279 characters on every run, no network, no input.

Run it:

```sh
node main.ts
```

It prints the character count and writes `/output/entry.txt`.
